## Project Overview

This repository contains my Machine Learning assignments for the AI-101 Introduction to Artificial Intelligence course. The assignments cover three different machine learning tasks involving structured data, text data, and sequence-to-sequence learning.

One task has been selected from each of the three assignment pools: Pool A, Pool B, and Pool C.

## Selected Tasks

### Pool A — Structured Data

**Task A1: Breast Cancer Diagnosis**

- **Problem Type:** Binary Classification
- **Dataset:** Breast Cancer Wisconsin Dataset
- **Objective:** Predict whether a breast tumor is malignant or benign using diagnostic features.
- **Learning Approach:** Supervised Machine Learning
- **Evaluation Metrics:** Accuracy, Precision, Recall, F1-Score, and ROC-AUC

### Pool B — Text and Metadata

**Task B2: Wine Critic Score Prediction**

- **Problem Type:** Regression
- **Dataset:** Kaggle Wine Reviews Dataset
- **Objective:** Predict wine critic scores using tasting descriptions and metadata.
- **Learning Approach:** Supervised Machine Learning
- **Models:** Baseline, Ridge Regression, SGDRegressor, and Gradient Boosting
- **Evaluation Metrics:** MAE, RMSE, and R² Score

### Pool C — Unstructured Sequence-to-Sequence

**Task C1: English-to-Urdu Machine Translation**

- **Problem Type:** Sequence-to-Sequence Learning
- **Dataset:** OPUS-100 (English–Urdu)
- **Objective:** Translate English sentences into Urdu using a machine learning model.
- **Learning Approach:** Supervised Sequence-to-Sequence Learning (Text → Text)
- **Pretrained Model:** Helsinki-NLP/opus-mt-en-ur
- **Evaluation Metrics:** BLEU and chrF
